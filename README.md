## How it works

`draw.py` (Pillow) renders `entry.png` (1024×1024). `main.py` (stdlib only) validates the PNG header and copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`:

```sh
python3 draw.py
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
